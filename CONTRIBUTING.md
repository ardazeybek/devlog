# Contributing to Devlog

Thanks for taking a look. You can help with a bug report, an idea, clearer wording, or a code change.

## Report a bug or suggest an idea

[Open an issue](https://github.com/ardazeybek/devlog/issues). For a bug, tell us what you expected, what happened, your operating system, and your VS Code version. Add steps to reproduce it if you can. Remove personal project names and other private details from screenshots.

For bigger changes, open an issue first so we can discuss the idea before you spend time on it.

## Send a change

1. Fork the repository and create a branch for your change.
2. Make a focused change and explain why it helps.
3. Run `npm test` with Node.js 20 or newer. For UI changes, include a screenshot.
4. Open a pull request against `main`.

Arda reviews pull requests before they are merged. Sending a pull request does not give direct write access to the project. Accepted code changes keep their author credit; GitHub lists contributors based on commits merged into the default branch.

Keep the interface in English and make wording easy to understand. Don't add telemetry, upload activity, or commit real coding history, passwords, or tokens. Keep screenshots and tests separate from real user data.

## AI use

AI-assisted contributions are welcome. Say which parts were generated or changed with AI, and explain what you checked. You should be able to discuss your proposed change and address review feedback.
