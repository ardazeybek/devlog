# Privacy

Your activity stays on your computer. Devlog does not send it to a server or collect analytics.

## What is saved

Devlog saves your daily coding time, language IDs, project names, and edit counts in VS Code's extension storage folder. It does not save your code, file paths, passwords, or the text you type. To recognize HTML in a Plain Text file, it briefly checks the document in memory.

## The browser dashboard

When you open the dashboard, Devlog starts a local server on `127.0.0.1`. A random token protects access to your activity. The server stops when the VS Code extension host closes. Your dashboard works without an internet connection.

GitHub and email links open only when you click them. They do not include your activity.

## Your saved data

Uninstalling Devlog may leave its storage folder behind. You can back it up or delete it with your file manager. Deleting it removes your saved activity.
