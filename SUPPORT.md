# Help and feedback

For bugs and ideas, [open a GitHub issue](https://github.com/ardazeybek/devlog/issues).

To contact Arda directly, email **quantastudio.dev@gmail.com**.

If Devlog cannot connect, keep VS Code open and run **Devlog: Open Dashboard** again. If your time isn't being counted, make sure tracking isn't paused and that you're editing a saved or unsaved file in the focused VS Code window.

Remove private information from screenshots or logs before sharing them.
