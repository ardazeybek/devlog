# media

Images used by the README and Marketplace listing, plus the extension icon. The packaged extension allowlist controls what ships.

- `devlog.svg`: sidebar symbol.
- `icon.png`: extension icon.
- `overview.gif`: animated tour of Overview, Projects, Reports and Achievements, using sample activity.
- `achievements.png`: achievement and title overview card.
- `screenshots/`: one screenshot per dashboard page, using sample activity. Regenerate them when the layout changes.
