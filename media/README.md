# media

Real dashboard captures rendered from the current source with synthetic activity. No personal activity or session tokens are included.

- `icon.png` and `devlog.svg`: existing extension identity assets.
- `overview.gif`: Overview opening animation, captured at 1440 × 1080 and encoded at 1200 × 900.
- `screenshots/`: all six dashboard pages captured after their opening animations finish.
- `achievements.png`: existing achievement and title overview card.

Regenerate captures when the interface changes. Capture tools and synthetic fixtures are kept outside the distributed extension. See `.vscodeignore` for package contents.
