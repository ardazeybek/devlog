# web/dashboard

Browser modules loaded through ES imports.

- `app.js`: entry, polling and navigation.
- `state.js`: session token and the current snapshot.
- `render.js`: range selection, page composition and scroll preservation.
- `analytics.js`: pure ranges, period comparisons, heat levels, CSV and backup documents.
- `helpers.js`: escaping, date keys, streak and small markup helpers.
- `components/`, `pages/`, `ui/`: see their READMEs.
