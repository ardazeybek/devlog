# web/dashboard/components

Reusable markup builders.

- `branches.js`: branch insight and project group tables.
- `chart.js`: daily time line chart.
- `empty.js`: empty-state block with a short next step.
- `goal.js`: daily and weekly goal cards.
- `heatmap.js`: last-year heatmap of day buttons.
- `journal.js`: coding journal form and notes.
- `language.js`: time by language.
- `metrics.js`: today, range and streak cards.
- `project-detail.js`: one project's totals and daily trend.
- `share-card.js`: SVG weekly share card.
- `table.js`: project table with selectable rows.
- `timeline.js`: 24-hour bar and session list for one day.
