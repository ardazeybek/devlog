# web/styles

Ordered stylesheets. The load order is defined in `web/index.html`.

- `foundation.css`: defaults, ambient background, shell, navigation and base inputs.
- `activity.css`: cards, metrics, charts, language rows, bars, streaks and goal ring.
- `awards.css`: achievements and filters.
- `forms-and-tables.css`: project tables, empty states, settings inputs and buttons.
- `responsive.css`: breakpoints and accessibility fallbacks.
- `titles.css`: title catalog, checks and its breakpoints.
- `typography.css`: local font fallbacks, numeric emphasis and scroll anchoring.
- `motion.css`: animation presentation and keyframes.
- `surfaces.css`: layered glass surfaces and their accessibility fallbacks.
- `palette.css`: final palette, depth and hover overrides.
- `status-and-languages.css`: connection issues and language symbols.
- `community.css`: community links in Settings.
- `select.css`: glass listboxes and keyboard focus styling.
- `celebrations.css`: reward cards, confetti and final small-screen overrides.
- `analytics.css`: range controls, heatmap, reports, project details and backup controls.
